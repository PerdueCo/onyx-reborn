About Onyx Reborn

A student employment system written in 1998, rebuilt for the web in 2026.

The story

In spring 1998, a student team called the Onyx group built BSSI as their capstone project at Gwinnett Technical Institute. It kept track of students in the Business Science programs and where they worked: their program, contact details, job-search goals, employer, hours and pay.

It worked well for its time, but time caught up with it. The program was 16-bit Visual Basic 4, which modern Windows can no longer run. Its records lived in fixed-width text files on a floppy drive, and students were identified by their Social Security numbers. Onyx Reborn keeps what the original got right and replaces everything that would not be acceptable today.

What changed

Area1998 BSSI2026 Onyx Reborn
Signing inType a Social Security number twiceEmail, password and a code from an authenticator app. No SSNs are collected or stored.
Where data livesFixed-width files on drive A:\A relational database with checks that stop bad or orphaned records
Main screenA switchboard of three buttonsAn overview dashboard with the numbers that matter
Who sees whatAnyone at the computer could see everythingAdministrator and Staff roles, with every change recorded
Jobs per studentOne employer, no historySeveral jobs at once, and ended jobs stay in the history
Where it runsOne PC in one labAny browser on a phone, laptop or desktop

How it came back

  1. April–May 1998BSSI is designed and built in Visual Basic 4 as a capstone project.
  2. Fall 2026The original source code and data files are recovered and read line by line to document how the old system really behaved, including its bugs.
  3. October 2026Onyx Reborn is planned and built with IBM Bob for the AngelHack “Modernize What Matters” challenge. The 1998 records are imported into the new database, without the Social Security numbers.
